# TOM4OS

Игровой лаунчер для Windows: библиотека локальных игр и игр Steam, управление с геймпада, локальные профили, темы и музыка.

[Скачать последнюю версию](https://github.com/sevimmamedov8-a11y/TOM4OS/releases/latest)

## Возможности

- Крупные карточки игр, поиск, избранное, коллекции и подборки.
- Перелистывание библиотеки мышью, клавишами PgUp/PgDn и кнопками LB/RB на геймпаде.
- Запуск локальных игр и игр Steam, параметры запуска и статистика времени игры.
- Отдельные профили пользователей и резервные копии.
- Игровые фоны, живые темы Silk, Lunar, Dune и Orbit, отключение анимаций.
- Каталог Spotify и SoundCloud внутри приложения, сохранённые ссылки и мини-плеер.
- Быстрые действия и центр управления звуком, оформлением и другими функциями.

## Запуск

Скачайте Windows x64 ZIP со страницы Releases, распакуйте его целиком и запустите `TOM4OS.exe`. Папка `native` должна оставаться рядом с программой. В архиве есть дополнительный запуск в режиме совместимости.

Для встроенной музыки требуются Microsoft Edge WebView2 Runtime и .NET Framework 4.8. Онлайн-сервисы определяют доступность и полноту воспроизведения; сохранённые ссылки TOM4OS не синхронизируются автоматически с личными медиатеками сервисов. Для игр Steam используется установленный клиент Steam.

Профили и библиотеки сохраняются в `%APPDATA%\TOM4OS`. Лаунчер не включает игры со скриншотов.
